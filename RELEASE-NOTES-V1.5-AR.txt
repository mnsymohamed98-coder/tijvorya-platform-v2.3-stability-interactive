TIJVORYA PLATFORM — RELEASE NOTES V1.5
تاريخ الإصدار: 21 يوليو 2026
الحالة: جاهز للبناء والنشر

أولًا: مركز تحكم إداري مستقل
- إنشاء Tijvorya Control Center بهوية بصرية وتخطيط مستقلين كليًا عن الموقع العام ولوحة التاجر.
- شريط جانبي إداري مخصص، شريط علوي تشغيلي، تنبيهات، تبديل اللغة، وحالة بيئة التشغيل.
- عدم استخدام هيدر أو فوتر الموقع العام داخل أي مسار إداري.
- إضافة صفحة سجل النشاط الإداري: /[locale]/admin/audit.

ثانيًا: الصفحة التنفيذية للإدارة
- مؤشرات قيمة الطلبات، إيراد المنصة، المتاجر النشطة، المستخدمين، قائمة مراجعة الريلز، والدعم.
- مركز حالة الخدمات: Supabase، OpenAI، الوسائط، الرسائل، المراجعة، وواجهة API.
- تنبيهات تشغيلية للمحتوى، الدعم، المخزون، والحسابات أو المتاجر المعلقة.
- توزيع حالات الطلبات وترتيب المتاجر بحسب قيمة الطلبات.
- قائمة أولوية المراجعة، آخر الإجراءات، واختصارات العمليات الأساسية.

ثالثًا: الصلاحيات الإدارية
تم اعتماد مستويات الوصول التالية:
- Super Admin
- Content Moderator
- Store Manager
- Customer Support
- Finance Manager

كل دور يرى الأقسام المسموح بها فقط، مع حجب المسارات غير المصرح بها داخل الواجهة وفي Proxy عند تشغيل Supabase.

رابعًا: حماية الإدارة
- إزالة رابط الإدارة وكلمة الإدارة من Footer الموقع العام.
- إبقاء الدخول الإداري عبر الرابط الخاص /ar/admin-access أو /en/admin-access.
- التحقق من حساب الإدارة وحالته وصلاحيته قبل إتاحة مسارات الإدارة عند اتصال Supabase.
- إضافة admin_role إلى مخطط profiles مع قيود القيم المعتمدة.
- ربط صلاحية الإدارة بسجل profiles بدل الاعتماد على بيانات المتصفح فقط.
