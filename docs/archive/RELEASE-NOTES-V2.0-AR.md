# Tijvorya 2.0 — ملاحظات الإصدار

## عنوان الإصدار
**Global Commerce Foundation**

## الجديد
- صفحة رئيسية احترافية ثنائية اللغة تركز على التحويل والثقة.
- سوق ببحث محسّن وفلاتر وفرز ومفضلة وحالة مخزون.
- SEO عالمي: metadata وhreflang وOpen Graph وrobots وmanifest وخريطة موقع ديناميكية.
- SEO وJSON-LD مستقلان لكل منتج ومتجر.
- نموذج تواصل حقيقي محفوظ في Supabase.
- عملة افتراضية قابلة للضبط.
- صفحة صحة للخدمات وإعدادات إنتاج أقوى.

## الأمان
- Checkout آمن يعيد حساب السعر والمخزون داخل PostgreSQL.
- خصم المخزون وإنشاء الطلب داخل معاملة واحدة.
- منع الإدخال المباشر للطلبات وعناصرها.
- منع اعتبار الإداري غير المصنف مديرًا عامًا.
- التحقق من الأدوار عبر جدول `profiles` الموثوق.
- حماية رفع Cloudinary وأدوات AI بحسب الدور والحالة.
- إدارة حساسة للحسابات عبر `admin_update_profile` ومبدأ أقل صلاحية.
- نموذج التواصل يستخدم Service Role على الخادم فقط.

## تجربة الاستخدام والوصول
- رابط تخطي للمحتوى وتركيز لوحة مفاتيح أوضح.
- تنقل نشط وتبديل لغة يحافظ على الصفحة.
- تحسين النصوص البديلة وتسميات الأزرار والحالات الحية.
- رسائل Checkout مفهومة بدل إظهار رموز أخطاء قاعدة البيانات.

## متطلبات الترقية
1. طبّق `supabase/migrations/20260731_v2_0_global_foundation.sql`.
2. أضف `SUPABASE_SERVICE_ROLE_KEY` إلى بيئة الخادم.
3. اضبط `NEXT_PUBLIC_SITE_URL` و`NEXT_PUBLIC_DEFAULT_CURRENCY`.
4. شغّل `npm ci && npm run verify` قبل النشر.
5. راجع `GLOBAL-LAUNCH-REPORT-AR.md` قبل استقبال عملاء حقيقيين.
