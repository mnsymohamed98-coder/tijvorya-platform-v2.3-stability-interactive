# Tijvorya v2.1.2 — إصلاح تسجيل الدخول للحسابات الجديدة

- إصلاح مشكلة إنشاء حساب جديد في وضع الاختبار المحلي ثم عدم القدرة على تسجيل الدخول به بعد تسجيل الخروج.
- حفظ حسابات الاختبار المحلية بشكل مستقل في المتصفح مع بصمة SHA-256 لكلمة المرور بدل حفظ كلمة المرور كنص مباشر.
- تسجيل الدخول يميّز الآن بين الحسابات التجريبية الجاهزة والحسابات التي أنشأها المستخدم.
- الحساب الجديد يُضاف إلى قائمة المستخدمين المحلية ويحفظ مع حالة الجلسة.
- إزالة تسجيل الدخول التلقائي بحساب التاجر التجريبي عند أول تشغيل.
- تحسين رسائل خطأ تسجيل الدخول حتى لا تقترح كلمة المرور التجريبية لحسابات غير تجريبية.
- إعادة ضبط بيانات Demo تمسح كذلك حسابات الاختبار المحلية.

> ملاحظة: هذا الإصلاح يجعل الاختبار المحلي يعمل بصورة صحيحة. عند نشر المنصة فعليًا يجب ربط Supabase حتى تكون الحسابات مشتركة بين الأجهزة والمستخدمين ولا تعتمد على LocalStorage.
