# Tijvorya 2.1 — Merchant Website Builder

## أهم التحسينات
- إضافة معالج إعداد للتاجر من 4 خطوات يظهر تلقائيًا للتاجر الذي لم يكمل إنشاء موقعه.
- جمع بيانات الهوية التجارية، المجال، العنوان التسويقي، الوصف، الاتصال، الموقع، ساعات العمل، التوصيل، الإرجاع، قصة العلامة، الشبكات الاجتماعية والشعار والغلاف.
- إنشاء موقع مستقل لكل متجر من 3 صفحات احترافية: الرئيسية، المنتجات، وعن المتجر.
- إضافة بحث وفلاتر وترتيب إلى كتالوج منتجات المتجر.
- إضافة معلومات التواصل، التوصيل، الإرجاع وساعات العمل إلى الموقع العام.
- تطبيق الثيم والألوان الخاصة بكل متجر على الصفحات الثلاث مع تصميم متجاوب للهاتف والكمبيوتر.
- إضافة روابط الصفحات الجديدة إلى sitemap وبيانات SEO مستقلة لصفحة المنتجات وصفحة عن المتجر.
- إضافة Website builder إلى تنقل لوحة التاجر لسهولة التعديل لاحقًا.
- تحسين تحميل مساحة العمل بعد تسجيل الدخول لتجنب إعادة تحميل بيانات الدور دون حاجة.
- حفظ ملف تعريف موقع التاجر داخل Supabase عبر حقل JSONB جديد مع ترقية منفصلة لنسخ 2.0.
