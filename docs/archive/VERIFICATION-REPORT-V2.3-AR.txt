مهم — حدود التحقق داخل هذه البيئة
---------------------------------
لم يتم اعتماد npm run verify / next build كاختبار مكتمل داخل بيئة التعديل، لأن node_modules المتاحة كانت جزئية وغير مكتملة، وTypeScript أبلغ عن type packages مفقودة مثل react/node. لذلك لا أدّعي أن Production Build الكامل تم هنا.

للتحقق النهائي على جهازك بعد فك الضغط:
  npm ci
  npm run verify
  npm run dev

كما أن تكاملات Supabase وGoogle OAuth وCloudinary الفعلية تحتاج مفاتيح البيئة/الاتصال الحقيقية حتى يمكن اختبارها end-to-end.
