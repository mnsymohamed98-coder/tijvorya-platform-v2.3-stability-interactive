# Tijvorya v1.8 — بداية نظام الريلز الذكي

## ما تم تنفيذه
- محرك ترتيب شخصي للريلز يعتمد على المشاهدة والحفظ والمتابعة واهتمامات فئات المنتجات.
- حفظ ملف الاهتمامات محليًا مع مراعاة عدم إرسال بيانات شخصية إلى AI.
- API لاستراتيجية ريلز كاملة: عنوان، Hook، كابشن، هاشتاقات، CTA، وقت نشر، وStoryboard من صور المنتج.
- API لتحليل أرقام الأداء وإنتاج درجة واقتراحات وتجربة تالية.
- دمج الاستراتيجية داخل نموذج إنشاء الريلز وحفظ الهاشتاقات ووقت النشر.
- توسعة مخطط Supabase بجداول أحداث الريلز ومقاييس التحويل والاحتفاظ.

## ما يحتاج خدمة خارجية لاحقًا
تحويل الصور فعليًا إلى ملف MP4 مع انتقالات وصوت يحتاج عامل معالجة فيديو مثل FFmpeg/Remotion على خادم منفصل أو خدمة Render. تم بناء الـStoryboard والبيانات والواجهات اللازمة، لكن لم تتم إضافة معالجة فيديو ثقيلة داخل خادم Next.js لتجنب مشاكل الأداء والتكلفة.
