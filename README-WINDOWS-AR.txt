Tijvorya Platform v1.3.0 — الثيمات والرسائل والذكاء الاصطناعي
================================================================

التشغيل المحلي:
1) فك الضغط خارج OneDrive، ويفضل داخل C:\Projects.
2) افتح المجلد الذي يحتوي مباشرة على package.json.
3) اضغط مرتين على START_TIJVORYA.bat.
4) اترك نافذة Tijvorya Dev Server مفتوحة.
5) افتح http://localhost:3000/ar

أهم الروابط:
- الرئيسية: http://localhost:3000/ar
- إعداد المتجر والثيم: http://localhost:3000/ar/merchant/store
- رسائل التاجر: http://localhost:3000/ar/merchant/messages
- رسائل العميل: http://localhost:3000/ar/messages
- مركز رسائل الإدارة: http://localhost:3000/ar/admin/messages
- دخول الإدارة: http://localhost:3000/ar/admin-access
- استوديو AI: http://localhost:3000/ar/merchant/ai-studio

الثيم المخصص لكل متجر:
- أربعة قوالب: عصري، بوتيك، بسيط، جريء.
- ألوان مستقلة للخلفية والبطاقات والنص واللون الأساسي.
- ثلاثة أنماط للغلاف، تخطيطان للمنتجات، وخيارات للخط والأزرار.
- شريط إعلان ومعاينة مباشرة قبل الحفظ.
- يحفظ الثيم في المتجر نفسه ويطبق تلقائيا على صفحته العامة.

نظام الرسائل:
- محادثات عميل ↔ متجر مرتبطة بالمنتج أو الطلب.
- صندوق رسائل خاص للعميل والتاجر والإدارة.
- عدادات غير المقروء، إغلاق وإعادة فتح المحادثات، وتحديث لحظي مع Supabase Realtime.
- سياسات RLS تمنع الوصول لغير أطراف المحادثة وتتحقق من دور مرسل الرسالة.
- يمكن للإدارة تشغيل النظام أو إيقافه من إعدادات المنصة.

ترقية قاعدة Supabase القائمة:
نفّذ الملف التالي مرة واحدة من SQL Editor في Supabase:
supabase\migrations\20260719_v1_3_store_themes_messages.sql

إنشاء قاعدة جديدة:
نفّذ:
supabase\schema.sql

تشغيل OpenAI الحقيقي:
1) افتح ملف .env.local داخل مجلد المشروع.
2) أضف:
   OPENAI_API_KEY=ضع_مفتاحك_هنا
   OPENAI_MODEL=gpt-5-mini
   AI_ENABLED=true
3) أوقف السيرفر بواسطة Ctrl+C ثم شغله من جديد.

مهم:
- مفتاح OpenAI سري ويجب ألا يبدأ اسمه بـ NEXT_PUBLIC_.
- بدون المفتاح تعمل أدوات AI بوضع تجريبي محلي عندما NEXT_PUBLIC_DEMO_MODE=true.
- الذكاء الاصطناعي يقترح المحتوى ولا ينشره أو يعتمده تلقائيا.
- لا تستخدم --force أو --legacy-peer-deps.

الفحص الكامل:
npm.cmd run verify
