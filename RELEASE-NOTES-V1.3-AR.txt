Tijvorya Platform v1.3.0
========================

الإضافات:
- محرر ثيم مستقل لكل متجر مع معاينة مباشرة.
- أربعة Presets قابلة للتخصيص: Modern / Boutique / Minimal / Bold.
- تخصيص الألوان والخطوط والغلاف وتخطيط المنتجات والأزرار واستدارة البطاقات.
- تطبيق الثيم المحفوظ على صفحة المتجر العامة.
- رسائل كاملة بين العميل والتاجر مع ربط اختياري بالمنتج أو الطلب.
- صندوق رسائل للتاجر والعميل ومركز مراقبة للإدارة.
- عدادات رسائل غير مقروءة في الهيدر ولوحة التحكم.
- رابط متابعة الطلب عبر المحادثة.
- إغلاق وإعادة فتح المحادثة من التاجر أو الإدارة.
- تحديث لحظي للمحادثات والرسائل عند استخدام Supabase Realtime.
- مفتاح إداري لتعطيل أو تفعيل نظام الرسائل.

الحماية:
- التحقق من ملكية المتجر وهوية العميل قبل إرسال الرسالة.
- منع تزوير sender_role في سياسات Supabase RLS.
- تثبيت سياق المحادثة ومنع تغيير العميل أو المتجر أو الطلب بعد إنشائها.
- تحديث عدادات الرسائل تلقائيا من قاعدة البيانات عبر Trigger موثوق.
- منع التاجر الجديد من تعديل متجر تابع لمستخدم آخر.

الإصلاحات والفحص:
- TypeScript: ناجح.
- ESLint: ناجح بدون أخطاء أو تحذيرات.
- Next.js Production Build: ناجح.
- npm registry: registry.npmjs.org فقط.
- لا توجد مفاتيح سرية ضمن الحزمة.
